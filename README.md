# Repo làm về chủ đề là ứng dụng mobile thương mại điện tử bán giày
### Công nghệ áp dụng
- Frontend: Kotlin XML, Kotlin Jetpack Compose.
- Backend: NodeJS, NestJS, TypeScript, TypeORM.
- Datbase: Postgres, TypeORM schema miration. 
- SDK android tối thiểu để chạy **Frontend Android**: **Android 7.0 (Nougat, API 24)**
- NodeJS version tối thiểu để chạy **Backend NestJS**: **22.14.0**
